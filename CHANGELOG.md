# Changelog

Friendly notes for every Framewise release live in [`release-notes/`](release-notes/), one file per version tag (for example `release-notes/v0.3.1.md`). The release workflow uses that file as the GitHub release description and adds a `versionCode: N` line at the bottom for the in-app updater. The app shows the same notes before you install an update and once after updating.
