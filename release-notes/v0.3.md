## What's new in Framewise 0.3

- Framewise can now update itself. It tells you when a new version is ready, and you install it with one tap.
- Clearer messages while you connect live view, so you can see what's happening at each step.
- A small floating Framewise button helps you jump back to the app.
- Updates are checked for safety before they install.

**Coming from 0.2?** Uninstall the old version once, then install this one. After that, updates work from inside the app.
