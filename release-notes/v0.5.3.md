## What's new in Framewise 0.5.3

- Fixed: "Could not reach GitHub" errors when checking for updates. Framewise now uses a lighter update check that GitHub doesn't limit.
- Tapping "Check for updates" many times in a row no longer causes errors. If GitHub is busy, Framewise waits and tries again later.
- Clearer messages: the camera Wi-Fi tip only shows when your phone is actually on the camera's Wi-Fi.
- Test reports are tidier: each update error is logged once, and closing the app no longer logs a USB disconnect.
